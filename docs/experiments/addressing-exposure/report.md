# Four-group exposure control

The delta-memory model acquired all four training groups after the longer budget:16/16 correct candidate rankings,4/4 complete groups and4/4 fixed raw training samples. The graph control remained8/16 correct,0/4 complete groups and2/4 raw samples. Frozen removal of the fitted delta readout drops training accuracy to50% and complete groups to0/4. This is a positive small-set acquisition result, not general binding or evidence that MLM replaces Transformers.

## Fixed protocol

[Protocol](../../evidence/addressing-exposure/protocol.json) and [plan](../../archive/README.md#historical-plans) were saved before training. Two independent runs reuse the unchanged `mlm.plasticity_run` driver, original English-only checkpoint, fresh AdamW, seed42, batch4 and existing role-rate configs. Each receives2,000QA+2,000English updates (4,000 optimizer updates each;8,000 total). Every one of four groups is presented exactly500 times.

The dataset is the earlier16-record subset: Bon/Bom, two color pairs (gold/lime and blue/pink), both fact orders, both queried entities and complementary assignments. No new training data or inference rules were introduced. The tiny reused development case has eight conditions; no test files were opened. Assessment is at the fixed endpoint, with no best-checkpoint selection.

This matches QA presentations per group to the old single-group run but uses four times as many total updates and English rehearsal updates. Against the old four-group run, both QA exposure and rehearsal increase together. Therefore it cannot isolate additional QA exposure from rehearsal or total optimization. The graph/delta endpoint comparison matches data, updates, role rates for shared tensors and sampling, but delta adds16,514 parameters and matrix state; it is not a parameter-count or compute-matched comparison.

Both longer-budget models score4/8 questions and0/2 complete groups on the tiny reused development case (zero complete eight-condition cases). Delta development query-flip fraction is0.5, but this does not amount to successful transfer. English loss is1.291641 graph and1.286896 delta, compared with source1.352696. Retention improved on this reused development set, which cannot establish broad English quality.

The previous four-group500-update failure was a finite-budget observation, not proof that the architecture could never acquire these groups. The delta success now establishes learnability of this narrow set under this schedule. One seed and two names do not establish a general algorithm or a stable advantage across runs.

## Post-hoc memory-output check

After observing the fitted delta endpoint, we added an explicitly post-hoc, training-only [ablation](../../evidence/addressing-exposure/ablate.py). It copies frozen params and sets only `memory_gain=0`, with no retraining, file mutation or test scoring. Keys, queries, writes and graph computation still execute.

With output enabled, training accuracy is100%, context/query flips100% and complete groups4/4. With output disabled, accuracy is50%, flips0%, complete groups0/4;8 of16 predictions change. The fitted network depends on the memory output channel for this task. This does not show that the matrix implements a general entity dictionary or isolate the benefit of training with memory: the network is coadapted and has extra parameters. No raw disabled-readout generations or English ablation scores were computed in this check.

## Verification

The [endpoint audit](../../evidence/addressing-exposure/audit.json) verifies all72 frozen input hashes, exact budgets,500 presentations per group, fresh optimizer states, identical sampler prefixes/initial fingerprints/initial assessments/rate policies versus earlier short runs, identical shared initial graph parameters across models, zero initial memory gate, and matched sampler/byte budgets/English-stream state across the two new runs. The driver rejects nonfinite updates; both runs completed normally. Original sources and prior probe outputs remain unchanged.

Model, training, inference and test sources are unchanged from the prior71-test passing diagnostic. The suite was not rerun for this experiment; verification instead checks those source hashes, actual run completion, endpoint invariants and analysis-script lint/format. Independent protocol/audit review found no material gaps. Reproducibility commands are in the protocol; initial/final checkpoints, config, environment, counter and sampler histories and full neural scores are under `runs/addressing-exposure-{none,delta}-g4-v1`. Running the protocol again requires fresh output directories.

## Next step

Replicate this exact acquisition comparison with additional predefined seeds before changing the architecture or increasing the dataset substantially. If acquisition is stable, use a separately frozen transfer evaluation across different entity pairs, names and fact wording. Keep memorization and transfer separate, retain a graph control and report the memory parameter/state cost. No checkpoint is promoted as a general-purpose model by this experiment.
