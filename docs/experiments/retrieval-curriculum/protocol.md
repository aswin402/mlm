# Controlled entity–fact retrieval curriculum

Authorized next experiment: learn which fact belongs to the queried entity, with controlled distractors and delay. Keep fixed graph/GRU architecture and existing retention-bias initialization; no new inference rules or learned topology.

Alternatives considered: add a memory bank (larger architectural confound), train more on the old reading suite (continued test reuse), or isolate binding in a controlled curriculum (chosen). Fixed English grammar and equal-four-byte color answers isolate retrieval from new wording and answer-length effects. Entity names are disjoint across this task's splits, not necessarily unseen in English pretraining or earlier experiments.

Data: offline factual assignments, paired context swaps, and four-question binding groups that also swap queried entity with context fixed. Three distractor levels 0/1/3 and exact filler byte lengths 0/64/128. Facts assign distinct colors. Query positions are balanced. Report all difficulty cells, full groups, correct and incorrect answer flips, raw greedy outputs, and story retention. Random independent two-choice guesses average 50% individual, 25% complete pairs and 6.25% complete four-question groups; these are reference rates, not significance claims.

Curriculum: two separate stages with fresh optimizers. Basic single-fact/no-delay stage: 500 updates, validation every 250, learning rate 0.0005, batch four, unroll 384. Binding/delay stage: 1,500 updates, validation every 500, same optimizer settings; initialize from basic development-selected checkpoint. Select only on the corresponding development target loss, with initial step zero eligible. Both architectures receive the same data/order/budget. Starting checkpoints are runs/memory-init-graph/initial.mlm and runs/memory-init-gru/initial.mlm, derived only from English. Do not warm-start from checkpoints chosen after inspecting old reading results.

Use 16 training, eight development and eight test names. Every synthetic training document must fit within one 384-byte unroll, preserving the gradient path from fact to answer. Mix 32 cached public training stories into binding training as explicit full-text rehearsal, and report measured retention; this does not guarantee preserved English. Basic stage has no rehearsal to isolate task learning.

Implement src/mlm/retrieval_data.py (offline generator/provenance), src/mlm/retrieval_eval.py (frozen scorer and diagnostics), tests/test_retrieval.py, and two configs. Retain existing data/models untouched. Prepare fresh data/retrieval-v1 with hashes and protect nonempty output paths. Tests verify deterministic preparation, no split overlap, labels/spans, balanced swaps/positions, exact delay, full-example unroll bounds, four-question grouping, and aggregation with deliberately wrong predictions. Run a smoke frozen evaluation before training. Freeze manifest/config/source hashes before training, then lock development-selected checkpoint hashes before opening test questions. No hyperparameter sweep.

Run both stages for both models; evaluate basic and binding development outcomes, then the locked final test and English retention. New task/test samples are untouched until final selection, but this remains one synthetic task and one seed, not confirmation of natural-language comprehension. Save failed probes and do not promote a checkpoint if broad quality regresses. Workspace has no git repository; save artifacts locally without a commit.
