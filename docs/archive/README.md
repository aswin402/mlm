# Documentation archive

## Historical plans

Obsolete one-off working plans were removed from the active Markdown tree for version0.0.1. Their complete original text and SHA-256 hashes are preserved in [original-markdown.json](original-markdown.json), keyed by their former repository paths. The same archive preserves original research/report bytes before links were updated.

[Migration map](migration.json) records old paths and their new locations. Historical protocol hashes describe the original experiment layout, not the reorganized release tree. To reproduce an old layout, restore the archived text at its original paths in an isolated checkout; keep the original numerical manifests unchanged.

Compact summaries and frozen experiment recipes live in [evidence](../evidence/). Full checkpoints, datasets, traces, optimizer states and raw run outputs remain local and are excluded from Git. Historical recipes expect the original paths and fresh output directories; they are not rerun automatically by this release.
